# 보장분석 빈칸을 메울 의료·보험 데이터 출처 조사

- 조사일: 2026-11-20 (웹 검색, 공식·언론 페이지 확인)
- 목적: Pick3 보장분석(보장분석 보고서 ↔ 병의원 기록 대조)에서 지금 빠진 정보를 어디서, 어떻게 얻을 수 있는지 정리
- 신뢰도 표시
  - **[확인]** 공식 페이지·공식 앱 설명·정부 보도에서 직접 확인
  - **[기사]** 언론 보도로만 확인
  - **[추정]** 서식에 대한 일반 지식이나 추론. 실물로 확인 필요

- **가장 중요한 발견**: 건강보험공단이 **2026-05-11부터 '요양급여내역'을 앱과 홈페이지에서 직접 열람·발급**합니다 [기사, 여러 매체 일치].

## 3. 추천 순서

**지금 바로 (고객이 PDF를 내려받아 단축어로 공유)**
1. **공단 요양급여내역 PDF** (건강보험25시, 10년, 진단명 포함): 진단비·수술비 청구 가능성 판단과 알릴의무 점검의 기반 데이터입니다. **가장 높은 가치입니다.**
2. **보험사 앱의 증권 PDF**: 가입일(일 단위)·특약·면책·감액·실손 세대를 확정해서, "이 진료가 보장기간 안인가"를 판정합니다.
3. **청구 후보 건의 진료비 영수증·세부산정내역서** (병원 앱, 본인, 3년 이내): 실손 예상액(급여/비급여)과 수술 종류를 증빙합니다. 후보 건만 골라 받으면 됩니다.
4. 보조: 나의건강기록 PDF (검진 10년, 진료·진단 5년, 투약)

**다음 (앱 화면 캡처)**
- 보험사 앱 '청구·지급 내역': 이미 받은 건을 빼서 같은 건을 다시 추천하지 않게 합니다.
- 내보험다보여, 내보험찾아줌: 전체 계약과 해지 계약 목록
- 실손24 진료내역 목록: 3년, 청구 가능한 병원 표시

**나중 (계약·허가 필요)**
- 하이픈·CODEF 같은 데이터 API: 월 10만~30만 원 이상. 진단명 상품이 있는지 먼저 확인해야 합니다.
- 의료 마이데이터 특수 전문기관 지정, 금융 마이데이터 허가: 비용과 요건 때문에 소규모로는 비현실적입니다.

**해석 주의**: 청구용 진단명에는 '의심'·'배제 진단(R/O)'이 섞일 수 있습니다 [추정]. 진단비 '확정진단' 여부와 알릴의무 판단은 **"가능성 있음 → 진단서로 확인"** 수준으로 표시합니다.

## 4. 법·동의 체크리스트 (설계사가 고객 건강정보를 다룰 때)

1. **민감정보 별도 동의** (개인정보보호법 제23조): 건강정보는 민감정보입니다. 다른 동의와 분리해서 목적·항목·보유기간·거부권과 불이익을 고지하고 동의를 받습니다. 항목을 빈칸으로 둔 동의서는 안 된다는 개인정보위 해석(2023)이 있습니다 [2차 자료].
2. **최소 수집** (제16조): 분석에 필요한 항목만 받습니다. 선택 항목에 동의하지 않았다고 서비스를 거부하지 않습니다.
3. **안전조치** (제29조, 민감정보 안전조치): 암호화·접근통제·접속기록을 갖춥니다. Supabase를 함께 쓰는 구조라면 계정별 권한 분리를 점검합니다.
4. **가족 데이터**: 가족 탭이 있으면 가족 **각자의 동의**가 필요합니다. 미성년자는 법정대리인 동의, 14세 미만은 제22조의2를 따릅니다.
5. **진료기록 대리 발급** (의료법 제21조, 시행규칙 제13조의3 [2차 자료]): 설계사가 병원에서 직접 떼려면 다음이 필요합니다.
   - 환자 자필서명 동의서와 위임장(별지 서식)
   - 환자와 신청인의 신분증
   - 친족이면 관계증명서

   병원 앱·온라인 발급은 **본인만** 가능합니다. 따라서 **고객 본인이 발급해 공유**하는 방식이 가장 깔끔합니다.
6. **보험계약 정보** (신용정보법): 신용정보원·보험사의 계약·지급 정보는 개인신용정보입니다. 고객이 직접 조회해 넘겨주는 방식이면 문제가 적지만, 저장·이용 목적을 고지하고 동의를 받습니다.
7. **보험업법·모집**:
   - 설계사가 보험금 청구를 대행하거나 손해액을 산정하면 손해사정 업무에 가까워질 수 있습니다. 그래서 Pick3는 **"청구 가능 후보 안내, 청구는 고객 본인이(실손24 등)"** 형태가 안전합니다 [추정: 금감원·손해사정 규정 원문 미확인].
   - 고객정보를 모집 목적 외로 쓰는 것은 처벌 사례가 있습니다.
   - 알릴의무 위반을 돕는 듯한 안내는 피합니다.
   - 허위 서류로 청구하면 보험사기 공범이 됩니다(금감원 경보).
8. **보험업법 시행령 제102조**: 보험회사 등의 민감정보 처리 근거 조항입니다. 설계사 개인에게도 적용되는지는 확인하지 못했습니다. 별도 동의를 기본으로 합니다.

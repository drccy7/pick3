📌 Pick3 인스타 맛집 저장

버튼 두 개만 누르면 준비가 끝납니다.

① 단축어 설치

버튼을 누르면 내 토큰이 복사되고 설치 화면이 열립니다. [단축어 추가]를 누르고, 토큰을 묻는 칸을 길게 눌러 붙여넣기 하세요.

✓ 토큰이 복사되었습니다

② 내 저장 목록 열기

저장한 맛집을 3곳씩 추천해 주는 화면입니다. 열린 화면에서 공유 → 홈 화면에 추가해 두면 편합니다.

내 저장 열기
사용법
  1. 인스타 게시물에서 캡션 '더 보기'를 펼치고 캡처
  2. 왼쪽 아래 썸네일 → 공유 → Pick3 저장
  3. 처음 '연결 허용'이 뜨면 항상 허용. 첫 저장은 30~50초 걸릴 수 있어요

더 빠르게: 설정 → 손쉬운 사용 → 터치 → 뒷면 탭 → 이중 탭 → Pick3 저장. 그러면 뒷면을 톡톡 두 번 두드리는 것으로 끝납니다.

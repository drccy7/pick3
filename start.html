① 단축어 설치

필요한 것을 눌러 [단축어 추가]만 누르세요(둘 다 해도 됨). 같은 이름의 예전 단축어가 있으면 먼저 지우세요.

🍽️ 맛집 저장 (Pick3 저장) 설치 🧾 의료비 저장 설치

② 단축어에 내 계정 연결

설치한 단축어 중 아무거나 하나를 누르세요. 단축어 앱이 열리고 "✅ 연결 완료"가 뜨면 끝입니다(두 단축어가 같이 연결됨).

처음엔 "파일 접근 허용"을 물을 수 있어요 → 허용.

단축어 앱이 안 열리면 Safari에서 이 페이지를 다시 열어 눌러 주세요.

② Pick3 열기

맛집 추천과 의료비 기록을 고르는 첫 화면입니다. 열린 화면에서 공유 → 홈 화면에 추가해 두면 앱처럼 쓸 수 있습니다.

Pick3 열기
사용법
  1. 인스타 게시물에서 캡션 '더 보기'를 펼치고 캡처
  2. 왼쪽 아래 썸네일 → 공유 → Pick3 저장 (맛집·의료비 결제 내역 화면은 자동으로 나뉘어 저장)
  3. 처방조제정보·진료비 PDF: 카톡에서 파일을 열고 공유 → 의료비 저장
  4. 처음 '연결 허용'이 뜨면 항상 허용. 첫 저장은 30~50초 걸릴 수 있어요

더 빠르게: 설정 → 손쉬운 사용 → 터치 → 뒷면 탭 → 이중 탭 → Pick3 저장. 그러면 뒷면을 톡톡 두 번 두드리는 것으로 끝납니다.

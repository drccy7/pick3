📌 Pick3 시작하기

단축어마다 버튼 두 개 [설치] → [연결]이면 끝납니다. 붙여넣기는 없습니다.

📸 Pick3 Save 맛집·의료비 화면 자동 구분

캡처 화면을 공유하거나 뒷면 탭으로 저장합니다. 대부분은 이것 하나면 됩니다.

① 설치

📄 Pick3 PDF PDF·파일용

처방조제정보·진료비 PDF를 카톡이나 파일 앱에서 공유해 저장합니다.

① 설치

① 설치: 단축어 앱이 열리면 [단축어 추가]. 안 열리면 파일 앱 → 다운로드에서 파일을 누르세요.
② 연결: 단축어 앱에서 "✅ 연결 완료"가 뜨면 끝. 파일 접근을 물으면 허용. 한 번 연결하면 두 단축어 모두 됩니다.
예전 단축어(Pick3 저장·의료비 저장·Pick3 맛집·Pick3 의료비)는 지워도 됩니다.

"단축어를 찾을 수 없음"이 뜨면 먼저 ① 설치를 해 주세요. 이름 뒤에 숫자(예: Pick3 Save 1)가 붙었다면 숫자를 지우세요.

📒 Pick3 열기

맛집 추천과 의료비 기록을 고르는 첫 화면입니다. 열린 화면에서 공유 → 홈 화면에 추가해 두면 앱처럼 쓸 수 있습니다.

Pick3 열기
사용법
  1. 인스타 게시물에서 캡션 '더 보기'를 펼치고 캡처
  2. 왼쪽 아래 썸네일 → 공유 → Pick3 Save (맛집·의료비 결제 내역 화면은 자동으로 나뉘어 저장)
  3. 처방조제정보·진료비 PDF: 카톡에서 파일을 열고 공유 → Pick3 PDF
  4. 처음 '연결 허용'이 뜨면 항상 허용. 첫 저장은 30~50초 걸릴 수 있어요

더 빠르게: 설정 → 손쉬운 사용 → 터치 → 뒷면 탭 → 이중 탭 → Pick3 Save. 그러면 뒷면을 톡톡 두 번 두드리는 것으로 끝납니다.
